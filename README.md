# Turbo Gramática

Jogo de corrida pseudo-3D para estudar português no estilo de pergaminhos de concurso (Cebraspe, Câmara). Cada corrida é uma aula seguida de questões: acertar respostas ganha velocidade, peças e prêmios.

## O que você precisa

- Windows 10 ou 11 (64 bits)
- Cerca de 150 MB de espaço livre
- Teclado ou controle Xbox (o controle é opcional, mas recomendado)
- Em PCs mais fracos, use a opção **Qualidade: leve** (veja abaixo)

## Como baixar e abrir

1. Baixe o arquivo **`TurboGramatica.exe`** (é um único arquivo, sem instalação).
2. Coloque-o em uma pasta qualquer, por exemplo `Documentos\Turbo Gramática`.
3. Dê dois cliques no arquivo.

### Aviso do Windows (SmartScreen)

Na primeira vez, o Windows pode mostrar **"O Windows protegeu o seu PC"**. Isso acontece porque o jogo não tem assinatura digital paga. Para abrir:

1. Clique em **Mais informações**.
2. Clique em **Executar assim mesmo**.

O jogo não acessa a internet, não instala nada no sistema e não mexe em outros programas.

## Controles

| Ação | Teclado | Controle Xbox |
|---|---|---|
| Acelerar | Seta para cima | A |
| Frear | Seta para baixo | (analógico esquerdo para baixo) |
| Virar | Setas esquerda/direita | Direcional ou analógico esquerdo |
| Nitro | Espaço | X |
| Box (pit stop) | P | Y |
| Escolher resposta esquerda / direita | Q / E | Ombro esquerdo / direito |
| Confirmar | Enter | A |
| Pausar / voltar | Esc | Start / B |

No menu, use as setas (ou o analógico) para mover e Enter (ou A) para escolher.

## Primeiros passos

1. Na tela inicial, escolha **CAMPEONATO** e depois uma categoria (GT, Stock, Rali ou Fórmula).
2. Cada categoria tem 12 corridas. A 12ª é a final, que revisa tudo da categoria.
3. Antes de cada corrida, leia a aula. Depois, responda as perguntas durante a prova.
4. Com o dinheiro das corridas, você compra peças na **GARAGEM** (motor, freios, aerodinâmica, etc.).
5. **TREINO LIVRE** deixa você estudar qualquer módulo sem correr.
6. **CADERNO DE ERROS** reúne as questões que você errou, para revisar.

## Opções

Em **CONTROLES E OPÇÕES** você encontra:

- **Qualidade**: `auto`, `alta` ou `leve`.
  - `auto` escolhe sozinho. Computadores com 2 núcleos ou menos já entram no modo leve.
  - `leve` deixa a pista mais curta e o som mais simples. Use se o jogo ficar travando.
  - A pista muda na próxima corrida. O som muda ao reabrir o jogo.

## Onde ficam os dados

Seu progresso fica salvo automaticamente em:

`%APPDATA%\Godot\app_userdata\Turbo Gramática Racer\save.json`

Para fazer backup, copie esse arquivo. Para zerar o progresso, apague só esse arquivo com o jogo fechado.

## Problemas comuns

- **A tela fica preta ou o jogo trava na corrida:** abra Opções e mude a Qualidade para `leve`.
- **O controle não responde:** feche o jogo, conecte o controle antes de abrir e reabra.
- **O som falha ou fica mudo:** confira o volume do Windows e a saída de áudio padrão.
